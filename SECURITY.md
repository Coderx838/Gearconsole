# Security Policy

## Supported Versions

The following versions of **Gear Console** are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take the security of **Gear Console** seriously. If you discover a security vulnerability or sensitive data exposure issue, please report it responsibly:

1. **Do NOT open a public issue** on GitHub.
2. Please report the issue privately using **[GitHub Security Advisories](https://github.com/Coderx838/Gearconsole/security/advisories/new)**.
3. Include detailed reproduction steps, relevant log snippets (with secrets redacted), and affected environment details (OS, Python version).

We will acknowledge your report within 48 hours and work on a timely resolution. Thank you for helping keep the open-source community safe!
